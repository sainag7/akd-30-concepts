# AKD 30.0 website concepts

Homepage directions for the AKD 30.0 "First in Flight" season.

**View them here: https://sainag7.github.io/akd-30-concepts/**

Round 2, inspired by real dance competition and festival sites:

- **Air Show**: team photos flying in formation with smoke trails, in a Carolina-blue sky
- **Night Show**: a dark, cinematic stage with searchlights and a sideways-scrolling team reel
- **Lineup Poster**: a printed show poster with a festival-style lineup

Round 1:

- **Flight Deck**: a Top Gun style cockpit HUD that climbs to 30,000 ft as you scroll
- **Kitty Hawk 1903**: a Wright Flyer patent blueprint with the event details as drafting notes
- **Carolina Skies**: an airline cabin window that opens into the sky, with a split-flap departures board

The lineup and board photos are last season's, used as sample content.
