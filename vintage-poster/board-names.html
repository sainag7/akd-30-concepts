Board names

Two ways to put names on the Board page, using this year's photos. Names are placeholders. Both list people left to right, the way old photo albums were labeled.

Option 1: Album captions

Recommended

Names are typed under each print, left to right, with back and front rows labeled for bigger groups. Everyone's name is visible right away, on any phone, with nothing to tap.

Option 2: Back of the photo

Tap a print to flip it over and read the names written on the back. It's more playful, but people have to tap each committee to see who's in it.

How it would work

Each committee in assets/data.js gets a members list in left-to-right order. Roles are optional. Groups shot in two rows list each row separately.

{ committee: "Directors", img: "directors.jpg",
  members: [["First Last", "Co-Director"], ["First Last", "Co-Director"], ["First Last", "Co-Director"]] },
{ committee: "Hospitality", img: "hospitality.jpg",
  rows: { "Back row": ["First Last", "First Last", "First Last", "First Last"],
          "Front row": ["First Last", "First Last"] } }

Send me a list like your committee spreadsheet, with names in left-to-right order for each photo, and I'll add them to whichever option you pick.
